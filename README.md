# ضبط رسانه دسترس‌پذیر

اپ فلاتر برای ضبط صدا و تصویر با رابط کاملاً فارسی و مناسب صفحه‌خوان (TalkBack).

## ساخت APK با گیت‌هاب (بدون نیاز به کامپیوتر)

۱. این پوشه را به یک مخزن جدید در گیت‌هاب پوش کنید (مثلاً با Termux:
```
git init
git add .
git commit -m "init"
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

۲. پس از پوش، به تب **Actions** در گیت‌هاب بروید. گردش کار به‌صورت خودکار اجرا می‌شود.

۳. پس از پایان موفق اجرا (حدود ۱۰ تا ۲۰ دقیقه)، در همان صفحه اجرا، پایین بخش
**Artifacts** فایل `app-release-apk` را دانلود کنید.

۴. فایل زیپ دانلودشده را باز کنید؛ داخل آن `app-release.apk` قرار دارد.
آن را روی گوشی نصب کنید (نیاز به اجازه «نصب از منابع ناشناس» دارد).

## نکته‌ها
- برای ضبط، دکمه ضبط ۳ ثانیه تأخیر دارد تا صدای صفحه‌خوان ضبط نشود.
- تب «ویرایش» برای پخش و برش (حالت انتخاب) است.
